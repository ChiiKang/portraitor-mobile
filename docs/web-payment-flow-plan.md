# Mobile Web Payment Flow - Superseded

The hosted Stripe redirect described by the former version of this document is
obsolete and must not be implemented in the mobile app.

The authoritative mobile billing contract is
[`docs/superpowers/specs/2026-08-07-apple-iap-design.md`](superpowers/specs/2026-08-07-apple-iap-design.md).
Mobile uses the platform store; Stripe remains a web-only payment rail.
Current delivery status is tracked in
[`docs/android-cross-platform-billing-plan.md`](android-cross-platform-billing-plan.md).
